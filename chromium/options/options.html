JDownloader behavior

Smart choice uses the direct stream on ordinary sites and the page URL where JDownloader’s site extractor is usually more reliable.

The filename hint requires the one-time JDownloader Packagizer rule described in the included README. Package names use the page title even without that rule.

Connects to Click'n'Load at http://127.0.0.1:9666.

Only connect directly to a JDownloader server you trust. Public HTTP exposes submitted video URLs without transport encryption.

Accepts LAN, VPN, WAN, or public IP addresses and hostnames over HTTP or HTTPS.

Uses the official MyJDownloader API, so no incoming port or VPN connection is required. The selected video URL and page title pass through MyJDownloader's encrypted service.

The password is used only to establish the encrypted session and is not saved in extension settings. Sign in again after restarting the browser.

Important: Protected DRM video cannot be downloaded by this extension or JDownloader. For ordinary video, start playback if no stream appears immediately.
